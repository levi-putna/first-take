# Audio assets

Place MP3 (or wav / m4a / aac) files here, then pass the path as a scene prop and play it with `<Audio src={staticFile(src)} />`.

| File | Typical role |
|------|----------------|
| `narration.mp3` | ElevenLabs VO, delayed 120 frames on the mix track |
| `bed-loop.mp3` | Optional looping bed (not generated yet) |
| `intro-jingle.mp3` | Optional sting on the lead-in (not generated yet) |
