# Structure: Myth vs fact

Use when **misconceptions block** adoption, trust, or safe use. Keep the
myth list short so each correction sticks.

## Shape

| # | Beat | Job | ~Share |
|---|------|-----|--------|
| 1 | Hook | Name the fog ("You've heard…") | 5–10% |
| 2 | Why myths matter | Cost of the wrong mental model | 10% |
| 3 | Myth / fact pairs | 2–3 pairs max, full teach each | 55–65% |
| 4 | Better model | One replacement framing | 10–15% |
| 5 | Recap + prompt | Quotable corrections + quiz | 10% |

## Beat writing tips

- State myths in everyday language people actually use.
- Give each myth enough time; do not rapid-fire five corrections.
- Visually separate myth (warning accent) from fact (primary accent).
- End with the better model, not only a pile of negations.

## On-screen text pattern

- "Myth" / "Fact" labels
- One sentence each
- Optional "So what at work" line under the fact

## Good fit examples

- Opening literacy myth-clearing
- "AI always understands the brief"
- "If it sounds confident, it must be true"

## Failures to avoid

- Straw-man myths nobody holds
- Correcting myths with equally fuzzy jargon
- Leaving the viewer with only "it's complicated"
